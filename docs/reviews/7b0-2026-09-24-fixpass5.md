## Most significant gaps

1. **Inlined copies silently lose their caller's input arguments** (all 10 Start-input exclusions in (b)/(c)).
   - Clarification 2 correctly stops the copies from re-initialising these inputs, because BP applies the
     caller's input over the initial value.
   - But the PAD output never applies that caller input either. `txt_QueueName`, `txt_LockName`,
     `txt_ConfigFileFullPath`, `txt_FileName`, `txt_SheetName`, `txt_InputFilePath`, `txt_EntryID`,
     `txt_PatternsCSV`, `txt_JPGPatternsCSV` and `txt_OutputFilePath` are never assigned in their flow.
   - The BP argument expressions (e.g. `[ConfigFileData.Queue Name]`) appear nowhere, and there is no `# TODO`.
   - This is pre-existing: inline shapes never bound call inputs, and item 4 said to keep inline behaviour. fp5
     only removed the last visible trace. It still breaks the project-wide "never silently drop" rule.
   - **Coordinator decision needed** on where the fix belongs, either:
     - (a) a one-line `# TODO` per excluded Start input at the copy start, naming the input and the caller's BP
       expression (small, `pad.py` only, arguably inside the item-8 clarification);
     - (b) a real binding `SET <input> TO <translated caller expr>` at copy start (a Task 5a/5b-style follow-up).
   - Today no rendered body references these variables, because the bodies are stubs. That will change once
     Task 5b translates them.
2. **Over-cautious collision TODO for an End-output hand-off.** Loader L253 `DataCollection`: the inlined page's
   same-named End output is captured into the host's same-named item (`outputs_stage_map`). This is the mirror
   image of the Start-input exclusion, and it is not a collision that Task 7b1 needs to rename. Excluding
   End-output-bound names captured under the same name (keeping the suppression, dropping the TODO) would stop 7b1
   from chasing a false positive. This is minor and has no behaviour change. Coordinator's call.
3. **Latent: the collision check only consults the immediate host page.** `_current_host_page` is reset to each
   inlined page for its nested inlines (`pad.py` L832/L895). Suppose an outer host declares X on the other role's
   side, and a nested inline declares X, but the intermediate page does not. Then the nested copy re-initialises
   X. There is no PID_171 instance (I checked Read Excel's declarations against Main's), and no test covers it.
4. **Latent: item-9 regex edge.** A `\b...\b` pattern never matches a data-item name that begins or ends with a
   non-word character (e.g. `Amount ($)`). There is no PID_171 instance. Minor.

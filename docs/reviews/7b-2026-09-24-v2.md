## Most significant gaps
1. **The consecutive-exception breach is unreachable in the real output.** The per-call inits at Performer L511-512 reset state that BP keeps across calls (no `<alwaysinit/>`). The tests hide this with `_logic_only` (`tests/generator/test_pad.py`, `_logic_only` helper). Fixing it needs parser/AST capture of `alwaysinit`, which is out of scope, plus an amendment to 7b0 item 8.
2. **The CFG walk puts join continuations only in the true arm** (`_render_decision_branch`/`_render_chain`, shared `visited`), so the false path silently loses them. It also drops loop back-edges with no TODO. The effect is latent in PID_171 and a real risk for the other automations.
3. **DECISION stubs lost their VERIFY marker.** 51 flagged comments became 47 unflagged empty `IF/ELSE/END` stubs (`condition.robin.j2` path, `pad.py` ~L2817). Branch contents render flat after them and read as real code.
4. **9 malformed `Lower(ExceptionType())` translations** (18 lines, listed above) moved from comments into live code.
5. **Variant selection is a substring heuristic** (`"system exception" in expr_lower`). It misfires on `login system exception` and on negated conditions. The key map is hardcoded in Python.
6. **The PID_171 variant test is too weak.** It is mutation-insensitive to which arm gets which status (M1 survives).
7. **Do item 2 is not met.** The counter init is not flagged with a citation, and the "deferred to 7d" rationale is incorrect.
8. **The throw message uses double-quoted literals** instead of reference `'…'` concatenation (ref L1272), at Performer L521/L534.
9. **Pre-existing issues:** invented `SET Tag_Item/Release_Item TO ""`, Tag/Defer as TODO instead of STOP (`vbo-action-mapping.md` L32), and `%SomeVar%` init. These belong in 7d item 4, which should be amended to name them.

## Verdict
**Blocked pending a design decision.** The coordinator or user needs to decide how BP data-item
lifetime maps to PAD:
- **Proposed rule:** items with `<alwaysinit/>` keep 7b0 item 8's per-call/per-copy init. Items without it are initialised once per flow run, at the top of the role's main body.
- **Prerequisite new task:** capture `<alwaysinit/>` (and `<private/>`) in `parser/process.py` → `BPDataItem` → builder.
- **Also needed:** a reopened 7b0 item 8 to apply the rule in `pad.py`.

After that, 7b needs another implementation pass, which can proceed independently now:
- drop `_logic_only`;
- fix the join/back-edge handling in the CFG walk, or emit a `# TODO` when a shape is unresolved;
- restore VERIFY on DECISION stubs;
- guard or fix the nested-paren `Lower()` output;
- replace substring variant detection with polarity-aware parsing;
- strengthen the branch-position variant test;
- use reference string-literal syntax in throw messages.
